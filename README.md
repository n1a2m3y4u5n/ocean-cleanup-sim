# 에너지 자립형 해양 쓰레기 수거 무인 선박 시뮬레이터

태양광으로 에너지를 자립하는 무인 선박이 바다의 쓰레기를 자동으로 찾아 수거하는 과정을 그리드 위에서 시뮬레이션하는 정적 웹앱입니다.

- 데모: https://ocean-cleanup-sim.fly.dev
- 수상: 2026 교내 청소년 과학 페어 은상 (2위)

## 소개

무인 선박이 시간 효율, 생태계 보호, 에너지 절약이라는 세 목표 사이에서 경로를 고르는 과정을 시각화합니다.
세 목표의 가중치를 슬라이더로 바꾸면 선박이 다목적 A* 알고리즘으로 경로를 다시 계산해서, 최단 경로 위주로 갈지
해양생물 구역을 피해 돌아갈지 에너지를 아껴 잠수를 줄일지가 실시간으로 바뀝니다.

## 주요 기능

- 다목적 A* 경로 탐색: 시간·생태 피해·에너지 세 가중치를 슬라이더로 조절
- 수면/심해 쓰레기 수거, 배터리와 태양광 충전으로 에너지 관리
- 드론 출격으로 탐지 범위 확장, 크라우드소싱으로 미탐지 구역 정보 수신
- 태풍 발생 시 경로 자동 회피
- 스마트 그물 ON/OFF (해양생물 구역을 지날 때 피해를 줄이되 이동 속도는 느려짐)
- 일시정지/초기화, 시뮬레이션 속도 조절(1×~20×)
- 배터리, 총 수거량, 생태 피해, 경과 시간 등 실시간 지표와 이벤트 로그

## 기술

바닐라 JavaScript, Canvas 2D. 빌드 과정 없는 정적 웹앱(HTML 한 파일)입니다.

## 실행 방법

```bash
open index.html
# 또는
python3 -m http.server
```
